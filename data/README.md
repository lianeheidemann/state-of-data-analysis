# Dataset

Este projeto usa a pesquisa **State of Data Brasil 2023** (Data Hackers / Kaggle).

Para rodar o notebook:

1. Baixe o dataset original da pesquisa State of Data Brasil 2023 (Data Hackers, disponível no Kaggle).
2. Salve o arquivo CSV nesta pasta como `data/State_of_data_BR_2023.csv`
3. Rode o notebook `analise_state_of_data_br_2023.ipynb` normalmente.

O arquivo não é versionado neste repositório por ser um dataset de terceiros.
