# Dataset

Este projeto usa a pesquisa **State of Data Brasil 2023** (Data Hackers / Kaggle),
disponível em <https://www.kaggle.com/datasets/datahackers/state-of-data-brazil-2023>.

O arquivo `State_of_data_BR_2023.csv` já está incluído nesta pasta, então basta
rodar o notebook `analise_state_of_data_br_2023.ipynb` diretamente.

Caso o arquivo seja removido no futuro, baixe a edição 2023 do link acima
(é necessário login no Kaggle) e salve novamente como `data/State_of_data_BR_2023.csv`.
